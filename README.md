# বন্ধুর বাজার (Bondhur Bazar) – ই-কমার্স ওয়েবসাইট

সম্পূর্ণ বিনামূল্যের স্ট্যাটিক ওয়েবসাইট (HTML + CSS + JavaScript)। কোনো সার্ভার, ডাটাবেস, পেইড API বা AI সাবস্ক্রিপশন লাগে না। অর্ডার WhatsApp-এ চলে যায়।

## কেন এই প্রযুক্তি বিনামূল্যে?
- **HTML/CSS/JS** – ব্রাউজারের নিজস্ব প্রযুক্তি, কোনো লাইসেন্স ফি নেই।
- **GitHub Pages** – স্ট্যাটিক ওয়েবসাইটের জন্য বিনামূল্যে হোস্টিং (সার্ভার ভাড়া লাগে না)।
- **WhatsApp (wa.me লিংক)** – বিনামূল্যে; কোনো API কী বা ব্যবসায়িক অ্যাকাউন্টের API লাগে না।
- **LocalStorage** – কার্ট ক্রেতার ব্রাউজারেই সংরক্ষিত থাকে।
- **Google Fonts (Hind Siliguri)** – বিনামূল্যের বাংলা ফন্ট। (ফন্ট লোড না হলেও ফোনের নিজস্ব বাংলা ফন্টে সাইট চলবে।)

## ফাইল কাঠামো
```
index.html, shop.html, categories.html, product.html, cart.html,
checkout.html, success.html, about.html, contact.html, landing.html
admin.html        ← নতুন পণ্যের কোড বানানোর সহায়ক
js/config.js      ← WhatsApp, Facebook, ডেলিভারি চার্জ, ক্যাটাগরি
js/products.js    ← সব পণ্য (নাম, দাম, বিবরণ, ছবি)
js/app.js, js/pages.js  ← সাইটের কোড (সাধারণত বদলাতে হয় না)
css/style.css     ← রং ও ডিজাইন
assets/           ← লোগো, ব্যানার
images/products/  ← পণ্যের ছবি
```

## প্রতিদিনের পরিবর্তন
| কী বদলাবেন | কোন ফাইলে |
|---|---|
| WhatsApp নম্বর / Facebook লিংক | `js/config.js` |
| ডেলিভারি চার্জ | `js/config.js` → `delivery` |
| নতুন ক্যাটাগরি | `js/config.js` → `categories` |
| দাম, বিবরণ, নাম | `js/products.js` |
| নতুন পণ্য | `admin.html` খুলে কোড বানিয়ে `js/products.js`-এ বসান |
| পণ্যের ছবি | `images/products/` ফোল্ডারে ছবি দিন; ফাইলের নাম `products.js`-এর `image` এর সঙ্গে মিলতে হবে |
| হোমপেজ স্লাইডার | `js/config.js` → `heroSlides` (নিচে দেখুন) |
| লোগো | `assets/logo.png` বদলান |

## হোমপেজ Animated Slider
৫টি স্লাইড আছে; প্রতি ৫ সেকেন্ডে নিজে থেকে ফেড হয়ে বদলায়। Previous/Next বাটন, নিচে ডট, মোবাইলে সোয়াইপ, কিবোর্ড তীর, থামানোর বাটন আছে এবং মাউস ছবির ওপর থাকলে সাময়িক থামে।

- **ছবি দেওয়া:** `images/banners/` ফোল্ডারে `slide-1.jpg … slide-5.jpg` নামে ছবি আপলোড করুন (কম্পিউটারের জন্য ১৬০০×৬০০ px)। ছবি না থাকলে প্রতিটি স্লাইডে রঙিন ডিজাইন দেখায়, কিছু ভাঙে না।
- **নতুন স্লাইড:** `js/config.js`-এর `heroSlides`-এ একটি `{ ... },` ব্লক কপি করে বসান।
- **স্লাইড বাদ:** ব্লকটি মুছুন। **ক্রম বদল:** ব্লকগুলো উপর-নিচ করুন।
- **সময়:** `sliderInterval: 5000` (মিলিসেকেন্ড; ৪০০০–৫০০০ রাখুন)।
- **মোবাইলের আলাদা ছবি:** `mobileImage` ফিল্ডে দিন (৮০০×৯০০ px)।
- ছবির **বাঁ দিক তুলনামূলক ফাঁকা** রাখুন, কারণ লেখা সেখানে বসে। ছবি বড় না করে ২০০–৩০০ KB-এর মধ্যে রাখলে সাইট দ্রুত চলবে।

## বিজ্ঞাপনী Landing Page
প্রতিটি পণ্যের জন্য আলাদা পেজ আগে থেকেই আছে: `landing.html?id=পণ্যের-id`
উদাহরণ: `landing.html?id=kalojira-honey`

চাইলে পণ্যের ভেতরে `landing` যোগ করে লেখা বদলাতে পারেন:
```js
landing: {
  headline: "কালোজিরা ফুলের মধু – বিশেষ স্বাদ",
  subheadline: "ঘরে বসে অর্ডার করুন",
  points: ["পয়েন্ট ১", "পয়েন্ট ২"],
  story: "পণ্যের গল্প…",
  image: "images/products/kalojira-banner.jpg"
}
```
এই লিংক Facebook পোস্ট বা বিজ্ঞাপনে ব্যবহার করতে পারবেন।

## ⚠️ প্রকাশের আগে অবশ্যই দেখুন
1. **লোগো:** আপনার আসল লোগো যুক্ত আছে (`assets/logo-original.png` অপরিবর্তিত; হেডারের জন্য `assets/logo.png` শুধু ফাঁকা মার্জিন ছাঁটা)।
2. **দাম:** শুধু মধুর চারটি দাম আপনার দেওয়া। খেজুর, গুড়, বাদাম, ড্রাই ফ্রুটসের দাম **নমুনা** – `products.js`-এ বদলান।
3. **ডেলিভারি চার্জ:** ঢাকায় ৬০ ও ঢাকার বাইরে ১২০ টাকা নমুনা – `config.js`-এ বদলান।
4. **পণ্যের ছবি:** ছবি না থাকলে সাময়িক প্লেসহোল্ডার দেখায়।
5. **Facebook প্রিভিউ:** প্রকাশের পর প্রতিটি HTML ফাইলের `<head>`-এ `https://abdulkaiyum2823-hub.github.io/bondhur-bazar/` লেখাটি আপনার আসল লিংক দিয়ে বদলান। `assets/og-image.jpg` (লোগোসহ ১২০০×৬৩০) তৈরি আছে; চাইলে ব্যানারসহ অন্য ছবি দিয়ে বদলাতে পারেন।

## ধাপে ধাপে বিনামূল্যে প্রকাশ (GitHub Pages)

### ধাপ ১: GitHub অ্যাকাউন্ট খুলুন
1. মোবাইলের ব্রাউজারে **github.com** খুলুন → **Sign up** চাপুন।
2. ইমেইল, পাসওয়ার্ড ও ইউজারনেম দিন (ইংরেজি ছোট হাতের, যেমন `bondhurbazar`)।
3. ইমেইলে আসা কোড দিয়ে নিশ্চিত করুন।

### ধাপ ২: রিপোজিটরি বানান
1. উপরে ডানে **+** → **New repository**।
2. Repository name: `bondhur-bazar`
3. **Public** বেছে নিন → **Create repository**।

### ধাপ ৩: কোড আপলোড
**কম্পিউটার থেকে (সহজ):**
1. ZIP ফাইল আনজিপ করুন।
2. রিপোজিটরিতে **uploading an existing file** লিংকে চাপুন।
3. আনজিপ করা **সব ফাইল ও ফোল্ডার** টেনে ছেড়ে দিন (ফোল্ডারসহ, `.nojekyll` ফাইলসহ)।
4. নিচে **Commit changes** চাপুন।

**শুধু মোবাইল থেকে:** মোবাইলে ফোল্ডার আপলোড কঠিন। Chrome-এ **Desktop site** চালু করে একই কাজ করুন, অথবা **Add file → Upload files** দিয়ে ফাইলগুলো ফোল্ডারভিত্তিকভাবে (`css`, `js`, `assets`, `images/products`) আলাদা আলাদা আপলোড করুন। কম্পিউটার পেলে একবারে সহজে হয়।

### ধাপ ৪: Pages চালু করুন
1. রিপোজিটরির **Settings** → বাঁ পাশে **Pages**।
2. **Source:** *Deploy from a branch*।
3. **Branch:** `main`, ফোল্ডার `/ (root)` → **Save**।

### ধাপ ৫: লিংক পান
১–৩ মিনিট পর একই পেজে লিংক দেখাবে:
`https://আপনার-ইউজারনেম.github.io/bondhur-bazar/`
এটিই আপনার ওয়েবসাইটের ঠিকানা। এটি Facebook পেজে ও WhatsApp-এ শেয়ার করুন।

### ধাপ ৬: মোবাইল থেকে আপডেট
1. GitHub-এ রিপোজিটরি খুলুন → যে ফাইল বদলাবেন (যেমন `js/products.js`) সেটি চাপুন।
2. উপরে ডানে **পেন্সিল (Edit)** আইকন → বদলান → **Commit changes**।
3. ১–২ মিনিটে সাইটে পরিবর্তন দেখা যাবে (না দেখালে ব্রাউজারে রিফ্রেশ করুন)।
4. ছবি যোগ: `images/products` ফোল্ডারে গিয়ে **Add file → Upload files**।

> কাস্টম ডোমেইন (.com) বাধ্যতামূলক নয়। ভবিষ্যতে চাইলে যোগ করা যায়, তবে সেটি পেইড।

## সীমাবদ্ধতা (লুকানো নয়)
- **অর্ডার সার্ভারে জমা হয় না।** অর্ডার WhatsApp মেসেজ হিসেবে আপনার কাছে আসে। ক্রেতা মেসেজে “Send” না চাপলে অর্ডার আসবে না। অর্ডার-সফল পেজে এ বিষয়ে সতর্ক করা আছে।
- **ক্রেতাদের কার্ট** শুধু তাদের নিজের ফোন/ব্রাউজারে থাকে।
- **পণ্যের আলাদা Facebook প্রিভিউ:** পণ্যের লিংক (`product.html?id=…`) একই ফাইল, তাই Facebook-এ সব পণ্যে সাধারণ সাইট প্রিভিউ দেখায়। পণ্যভিত্তিক প্রিভিউ চাইলে ভবিষ্যতে প্রতি পণ্যের জন্য আলাদা HTML ফাইল দরকার।
- **অর্ডার নম্বর** ব্রাউজারে তৈরি হয়; এটি রেফারেন্সের জন্য, কঠোরভাবে ইউনিক নিশ্চিত নয়।
- **অনলাইন পেমেন্ট নেই** (bKash/Nagad গেটওয়ে সাধারণত ফি/অনুমোদন লাগে)। পেমেন্ট WhatsApp-এ আলোচনা করে নিতে হবে।
- **অর্ডার সংরক্ষণের বিনামূল্যে বিকল্প (ভবিষ্যতে):**
  - *Google Sheets + Apps Script:* অর্ডার ফর্ম থেকে স্বয়ংক্রিয়ভাবে Google Sheet-এ জমা।
  - *Formspree / Web3Forms ফ্রি প্ল্যান:* ইমেইলে অর্ডার পাঠানো।
  - *Firebase (Spark ফ্রি প্ল্যান):* ডাটাবেস।
  চাইলে পরবর্তী ধাপে এর যেকোনো একটি যুক্ত করে দিতে পারি।
